OFSYE HTML5 Prototype
=====================

Open index.html in a web browser.

Files:
- index.html: student-facing homepage
- first-two-years.html: student journey guide
- programs.html: programs and experiences
- support.html: student support directory
- events.html: events and opportunity layout
- about.html: mission and office information
- faculty-staff.html: faculty/staff partnership page
- styles.css: all visual styling
- script.js: mobile navigation and prototype-link notices

Notes:
- Internal navigation works.
- Links marked as prototype links are intentionally placeholders.
- Replace bracketed contact information and external resource links before publishing.
- The layout is responsive and uses semantic HTML5.
